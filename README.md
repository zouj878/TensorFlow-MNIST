# TensorFlow MNIST Handwritten Digit Recognition
> A beginner TensorFlow project that trains a neural network to classify MNIST handwritten digits.

## Project Overview
- Dataset: MNIST handwritten digits (0~9), containing 60,000 training samples and 10,000 test samples
- Model: Simple fully-connected neural network
- Training: 5 epochs, achieving over 97% accuracy on the test set
- Visualization: Randomly select 5 images after training to visualize prediction results
